# 在 iPhone 上安装 FitLog

FitLog 是 PWA，**不需要 App Store、不需要 Apple 开发者账号、不需要 TestFlight**。
用 Safari 打开网页，加一次「主屏幕」，之后就像 App 一样用：独立图标、全屏无地址栏、断网也能打开。

> 地址：**https://fit.kjsa.cn**

---

## 一、安装（30 秒）

1. **用 Safari 打开** https://fit.kjsa.cn
2. 点底部中间的 **分享按钮**（方框 + 向上箭头）
3. 往下滑，点 **「添加到主屏幕」**
4. 名称会默认填好 `FitLog`，点右上角 **「添加」**

回到桌面，会看到哑铃图标。点开就是全屏应用。

> **必须用 Safari。** iOS 上只有 Safari 能安装 PWA。
> Chrome、Edge、Firefox、以及微信/QQ 内置浏览器都**不行**——它们没有「添加到主屏幕」这个入口，
> 就算有，装出来的也只是个书签，会带地址栏、断网打不开。

---

## 二、第一次打开要登录一次

PWA 在 iOS 上有**自己独立的存储空间**，和 Safari 里的登录状态不共享。
所以第一次从桌面图标打开时需要重新输一次账号密码，之后就记住了。

- 账号：`admin`
- 密码：你改过之后的那个（部署时是随机生成的，后来应该改过了）

如果忘了密码，在服务器上重置：

```bash
cd /opt/fitlog
docker compose exec fitlog node -e "
const D=require('better-sqlite3');const db=new D('/data/fitlog.db');
console.log(db.prepare('select id,username from users').all());
"
```

改密码走网页「我的 → 修改密码」最省事；实在进不去再动数据库。

---

## 三、装好之后是什么样

| 能力 | 状态 |
|---|---|
| 独立图标、启动动画、全屏无地址栏 | ✅ |
| 断网打开、翻已看过的页面 | ✅ app 骨架全部缓存在本地 |
| 断网看动作动图 | ✅ 看过的才会缓存（1285 个 GIF 太大，不预下载） |
| 断网记录训练 | ❌ 会提示「当前离线」，联网后才能保存 |
| 横屏 | 锁定竖屏 |
| 后台推送 | ❌ iOS 限制，PWA 只能在网页打开时收到 |

**关于训练数据**：`/api` 请求**永不缓存**。这是故意的——练完一组看到的是上次的组数，
比看不到更糟。所以断网时页面能打开，但数据要联网才有。

---

## 四、健身房里的弱网

这是 PWA 相比普通网页最大的改进：

- 页面导航 2.5 秒拿不到响应就直接用本地缓存渲染，不会一直转圈
- 已看过的动作动图不会再走网络
- 接口超时会明确提示「请求超时」，不会卡死

---

## 五、更新

**不用管**，下次打开自动就是新版。

原理：Service Worker 每次启动都会向服务器确认一次 `/sw.js`（这个文件设了 `no-store`），
发现有变化就下载新版本并接管。所以你不需要「检查更新」。

如果想立刻强制更新：删掉桌面图标，重新按第一节装一遍。

---

## 六、卸载

长按桌面图标 →「移除 App」→「删除主屏幕图标」。

**只会删掉手机上的图标和本地缓存，服务器上的训练数据一个字都不会少。**
重新装回来登录即可。

---

## 七、常见问题

**Q：图标是一个模糊的网页截图，不是哑铃**

说明安装时用的是旧版本（那时还没有 PNG 图标）。删掉图标重新装一次。

如果重装还是不对，是 Safari 缓存了旧的 `apple-touch-icon`：设置 → Safari → 清除历史记录与网站数据，
然后重新装。（会顺带清掉网页登录态，重登即可。）

**Q：点开是白屏**

99% 是用 Chrome / 微信打开后「添加到主屏幕」的——那装出来的是书签。删掉，改用 Safari 重装。

如果确认是 Safari 装的还白屏：设置 → Safari → 高级 → 网站数据 → 找到 `fit.kjsa.cn` 删除，再重装。

**Q：过一段时间又要重新登录**

iOS 会清理长期不用的 PWA 存储（一般 7 天以上完全没打开）。这是系统行为，改不了。
常用就不会掉。数据都在服务器上，重新登录即可。

**Q：顶部状态栏和底部 Home 条压到内容了**

已经在 CSS 里用 `env(safe-area-inset-*)` 适配过。如果还是压到，截个图告诉我。

**Q：能不能同时装在 iPad 上**

可以，步骤一样。iPad 的分享按钮在顶部。

## 八、如果以后想要「真正的 App」

PWA 的边界很清楚：**不能上架、不能推送、不能读健康数据、断网不能写**。

这些都能用 Capacitor 补上（把同一套前端打进原生壳），前提是：

- Apple 开发者账号（$99/年）
- Mac + Xcode（你有）
- 前端要小改一处：现在的接口路径是 `/api/xxx` 的绝对路径，
  打包成本地资源后需要改成 `https://fit.kjsa.cn/api/xxx`，否则请求会打到 WebView 自己身上

**只自己用不上架的话**，不走 App Store 审核，可以绕开 4.2 那条「纯网页壳」的拒审理由，
直接 Xcode 装到手机，或者用 TestFlight 分发给自己。

要做的原生增强（按性价比排序）：

1. **本地离线队列** —— 组数先存 IndexedDB，联网后补传。这是健身房场景最实在的一条
2. **HealthKit 写入** —— 训练同步到「健康」App
3. **Face ID 解锁** —— 训练数据算隐私
4. **Apple Watch** —— 记组数，工作量最大

要做的话告诉我，前端那处改造 + Capacitor 工程配置我可以一并处理。
